# @videojs/mux

Mux identity helpers shared by the Video.js Mux adapters: playback, poster, and storyboard URL building, DRM query
parameters, and the `MuxSourceBase` shape. Private to the workspace and bundled into `@videojs/mux-video`, `@videojs/mux-audio`, and
`@videojs/mux-data`; to play Mux media, install one of the first two.
