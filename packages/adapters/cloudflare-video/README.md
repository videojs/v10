# @videojs/cloudflare-video

## AI Quickstart

Using an AI coding agent? Install the [Video.js skill](https://github.com/videojs/skills) so it reads the docs that
match this package version before writing code. Then print installation instructions with this adapter selected:

```sh
npx @videojs/react agents init --media cloudflare
npx @videojs/html agents init --media cloudflare
```

Cloudflare Stream playback adapter for Video.js. It exposes the adapter, its props, and defaults; the HTML and React façades live in `@videojs/html` and
`@videojs/react`.

## Installation

```bash
pnpm add @videojs/html @videojs/cloudflare-video
# or
pnpm add @videojs/react @videojs/cloudflare-video
```

## Usage

```ts
import '@videojs/html/media/cloudflare-video';
```
