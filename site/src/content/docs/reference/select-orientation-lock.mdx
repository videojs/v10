## Usage

`selectOrientationLock` reads the <DocsLink slug="reference/feature-orientation-lock">orientation lock feature</DocsLink> from player state. It returns `undefined` when the feature is not configured.

<FrameworkCase frameworks={["react"]}>
Pass it to <DocsLink slug="reference/use-player">`usePlayer`</DocsLink> to subscribe to orientation lock state.

```tsx
const orientationLock = usePlayer(selectOrientationLock);
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Pass it to <DocsLink slug="reference/player-controller">`PlayerController`</DocsLink> to subscribe from a custom element.

```ts
class OrientationLockControl extends UIElement {
  readonly #orientationLock = new PlayerController(this, playerContext, selectOrientationLock);
}
```
</FrameworkCase>
