## Import

<FrameworkCase frameworks={["react"]}>
```tsx
import { selectError, usePlayer } from '@videojs/react';
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import { PlayerController, UIElement, playerContext, selectError } from '@videojs/html';
```
</FrameworkCase>

## Usage

`selectError` reads the <DocsLink slug="reference/feature-error">error feature</DocsLink> from player state. It returns `undefined` when the feature is not configured.

<FrameworkCase frameworks={["react"]}>
Pass it to <DocsLink slug="reference/use-player">`usePlayer`</DocsLink> to subscribe to error state.

```tsx
const error = usePlayer(selectError);
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Pass it to <DocsLink slug="reference/player-controller">`PlayerController`</DocsLink> to subscribe from a custom element.

```ts
class ErrorElement extends UIElement {
  readonly #error = new PlayerController(this, playerContext, selectError);
}
```
</FrameworkCase>
