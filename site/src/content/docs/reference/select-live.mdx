## Import

<FrameworkCase frameworks={["react"]}>
```tsx
import { selectLive, usePlayer } from '@videojs/react';
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import { PlayerController, UIElement, playerContext, selectLive } from '@videojs/html';
```
</FrameworkCase>

## Usage

`selectLive` reads the <DocsLink slug="reference/feature-live">live feature</DocsLink> from player state. It returns `undefined` when the feature is not configured.

<FrameworkCase frameworks={["react"]}>
Pass it to <DocsLink slug="reference/use-player">`usePlayer`</DocsLink> to subscribe to live state.

```tsx
const live = usePlayer(selectLive);
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Pass it to <DocsLink slug="reference/player-controller">`PlayerController`</DocsLink> to subscribe from a custom element.

```ts
class LiveElement extends UIElement {
  readonly #live = new PlayerController(this, playerContext, selectLive);
}
```
</FrameworkCase>
