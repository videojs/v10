The minimal skin of the audio preset: the same player and the same controls in a visually lighter design, closer to a classic control bar. <DocsLink slug="reference/audio-skin">AudioSkin</DocsLink> is the same preset's other variant. See <DocsLink slug="concepts/skins">Skins</DocsLink> for how packaged skins work and <DocsLink slug="concepts/presets">Presets</DocsLink> for what the audio preset ships.

## Import

<SkinImports preset="audio" react="MinimalAudioSkin" minimal />

## Usage

The skin goes between the player and the media element. It renders its controls around the media.

<FrameworkCase frameworks={["react"]}>
```tsx
<AudioPlayer>
  <MinimalAudioSkin>
    <Audio src="audio.mp3" />
  </MinimalAudioSkin>
</AudioPlayer>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<audio-player>
  <audio-minimal-skin>
    <audio src="audio.mp3"></audio>
  </audio-minimal-skin>
</audio-player>
```
</FrameworkCase>

## Styling

Packaged skins style themselves and expose a small set of public CSS custom properties. Everything else inside the skin is private and may change between releases. <DocsLink slug="how-to/customize-skins" anchor="style-a-packaged-skin">Customize skins</DocsLink> documents the properties. When you need deeper changes, install the skin's source.
