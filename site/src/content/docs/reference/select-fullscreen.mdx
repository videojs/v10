## Import

<FrameworkCase frameworks={["react"]}>
```tsx
import { selectFullscreen, usePlayer } from '@videojs/react';
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import { PlayerController, UIElement, playerContext, selectFullscreen } from '@videojs/html';
```
</FrameworkCase>

## Usage

`selectFullscreen` reads the <DocsLink slug="reference/feature-fullscreen">fullscreen feature</DocsLink> from player state. It returns `undefined` when the feature is not configured.

<FrameworkCase frameworks={["react"]}>
Pass it to <DocsLink slug="reference/use-player">`usePlayer`</DocsLink> to subscribe to fullscreen state.

```tsx
const fullscreen = usePlayer(selectFullscreen);
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Pass it to <DocsLink slug="reference/player-controller">`PlayerController`</DocsLink> to subscribe from a custom element.

```ts
class FullscreenControl extends UIElement {
  readonly #fullscreen = new PlayerController(this, playerContext, selectFullscreen);
}
```
</FrameworkCase>
