Video element that plays TikTok videos through the [TikTok embed player](https://developers.tiktok.com/doc/embed-player). TikTok videos are portrait, and the player refuses to draw its chrome below 325×578, so the element starts at that size rather than the usual 300×150.

## Load a source

`src` takes a TikTok video URL or a raw numeric video id. The `@user/video/<id>` URLs the app hands out, `share/video/<id>` links, and `player/v1/<id>` embed URLs all work.

<FrameworkCase frameworks={["react"]}>
```tsx
<TikTokVideo src="https://www.tiktok.com/@_luwes/video/7527476667770522893" />
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<tiktok-video src="https://www.tiktok.com/@_luwes/video/7527476667770522893"></tiktok-video>
```
</FrameworkCase>

## Controls

TikTok always draws part of its own chrome: the center play button, author header, and social rail are always visible. `controls` adds the progress bar and control buttons on top of those. Without `controls`, the element ignores pointer events, so a player skin above it receives every click.

## The dormant player

TikTok builds its player lazily: until something starts playback, the embed has no media element, reports a duration of 0, and silently drops commands. The element works around this by bringing the player up with a muted autoplay it immediately parks, so the embed answers play, pause, and seek before the first play. Two settings opt out: `preload="none"` trades those working controls back for an untouched network, and `controls` hands playback to TikTok's own chrome instead.

## Playback surface

- Mute works, but there's no volume control: the embed reports a level but takes no command to set one.
- No playback rate and no text tracks; captions are toggled with `engine.tiktok.closed_caption`.
- `poster` and `playsInline` never reach the embed: it always plays inline and draws the video's own cover image.
- Changing `controls` or `loop` after the embed is up rebuilds it; rewriting the iframe URL is the only reload TikTok allows.

## Player parameters

Pass [TikTok player parameters](https://developers.tiktok.com/doc/embed-player) under `source.engine.tiktok`, spelled exactly as TikTok spells them — each one `0` or `1`. <DocsLink slug="concepts/media-sources">Media Sources</DocsLink> covers how engine options fit into a structured source.

| Param | It toggles | Default |
|---|---|---|
| `closed_caption` | The closed captions button | `1` |
| `description` | The video description | `0` |
| `fullscreen_button` | The fullscreen button | `1` |
| `music_info` | The music info banner | `0` |
| `native_context_menu` | TikTok's own context menu | `1` |
| `play_button` | The center play button | `1` |
| `progress_bar` | The progress bar | `1` |
| `rel` | What plays next: `1` for TikTok's recommendations, `0` for the author's own videos | `0` |
| `timestamp` | The timestamp | `1` |
| `volume_control` | The volume control | `1` |

`autoplay`, `controls`, `loop`, and `muted` come from the props of the same name, so they have no `engine.tiktok` spelling. Anything TikTok adds next passes through the same way.

<FrameworkCase frameworks={["react"]}>
```tsx
<TikTokVideo
  source={{
    src: 'https://www.tiktok.com/@_luwes/video/7527476667770522893',
    engine: { tiktok: { closed_caption: 0, rel: 1 } },
  }}
/>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
const video = document.querySelector('tiktok-video');
video.source = {
  src: 'https://www.tiktok.com/@_luwes/video/7527476667770522893',
  engine: { tiktok: { closed_caption: 0, rel: 1 } },
};
```
</FrameworkCase>
