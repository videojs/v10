The only skin of the background preset: a chrome-less surface that sizes ambient video with no visible controls. See <DocsLink slug="concepts/skins">Skins</DocsLink> for how packaged skins work and <DocsLink slug="concepts/presets">Presets</DocsLink> for what the background preset ships.

## Import

<SkinImports preset="background" react="BackgroundVideoSkin" />

## Usage

The skin nests between the player and the media element and renders its controls around the media it wraps.

<FrameworkCase frameworks={["react"]}>
```tsx
<BackgroundVideoPlayer>
  <BackgroundVideoSkin>
    <BackgroundVideo src="video.mp4" />
  </BackgroundVideoSkin>
</BackgroundVideoPlayer>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<background-video-player>
  <background-video-skin>
    <background-video src="video.mp4"></background-video>
  </background-video-skin>
</background-video-player>
```
</FrameworkCase>

## Styling

Packaged skins style themselves and expose a small set of public CSS custom properties. Everything else inside the skin is private and may change between releases. <DocsLink slug="how-to/customize-skins">Customize skins</DocsLink> documents the properties and the ejection path when you need deeper changes.
