## Import

<FrameworkCase frameworks={["react"]}>
```tsx
import { selectVolume, usePlayer } from '@videojs/react';
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import { PlayerController, UIElement, playerContext, selectVolume } from '@videojs/html';
```
</FrameworkCase>

## Usage

`selectVolume` reads the <DocsLink slug="reference/feature-volume">volume feature</DocsLink> from player state. It returns `undefined` when the feature is not configured.

<FrameworkCase frameworks={["react"]}>
Pass it to <DocsLink slug="reference/use-player">`usePlayer`</DocsLink> to subscribe to volume state.

```tsx
const volume = usePlayer(selectVolume);
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Pass it to <DocsLink slug="reference/player-controller">`PlayerController`</DocsLink> to subscribe from a custom element.

```ts
class VolumeControl extends UIElement {
  readonly #volume = new PlayerController(this, playerContext, selectVolume);
}
```
</FrameworkCase>
