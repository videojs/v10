The minimal skin of the live audio preset: the same player and the same controls in a visually lighter design, closer to a classic control bar. Like the default skin, it shows a Live button in place of time controls. <DocsLink slug="reference/live-audio-skin">LiveAudioSkin</DocsLink> is the same preset's other variant. See <DocsLink slug="concepts/skins">Skins</DocsLink> for how packaged skins work and <DocsLink slug="concepts/presets">Presets</DocsLink> for what the live audio preset ships.

## Import

<SkinImports preset="live-audio" react="MinimalLiveAudioSkin" minimal />

## Usage

The skin nests between the player and the media element and renders its controls around the media it wraps.

<FrameworkCase frameworks={["react"]}>
```tsx
<LiveAudioPlayer>
  <MinimalLiveAudioSkin>
    <Audio src="live.m3u8" />
  </MinimalLiveAudioSkin>
</LiveAudioPlayer>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<live-audio-player>
  <live-audio-minimal-skin>
    <audio src="live.m3u8"></audio>
  </live-audio-minimal-skin>
</live-audio-player>
```
</FrameworkCase>

## Styling

Packaged skins style themselves and expose a small set of public CSS custom properties. Everything else inside the skin is private and may change between releases. <DocsLink slug="how-to/customize-skins">Customize skins</DocsLink> documents the properties and the ejection path when you need deeper changes.
