## Behavior

A placeholder is a tiny copy of your poster — twenty pixels wide is plenty. It arrives in a few kilobytes, so viewers see something the moment the page paints instead of an empty box. Blur it in CSS and the full poster fades in over the top. That effect is usually called blur-up.

Set the URL on the player, not on this component:

<FrameworkCase frameworks={["react"]}>
```tsx
<Player.Provider placeholder="tiny.jpg" />
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<video-player placeholder="tiny.jpg"></video-player>
```
</FrameworkCase>

The component reads the resolved value and sets it as its `background-image`. It renders one empty element and adds nothing inside it.

Render it before the <DocsLink slug="reference/poster">poster</DocsLink> so the poster paints on top. The two share a visibility rule: both show before playback starts and hide once it does. There is no handoff between them — the poster is simply painted over the placeholder as it loads, and wherever the poster does not reach, such as the bars left by `object-fit: contain`, the placeholder keeps showing through.

## Styling

| Attribute | Values | Description |
|-----------|--------|-------------|
| `data-visible` | Present / absent | Present before playback starts |

The component sets `background-image` and nothing else. Size it, position it, and blur it yourself:

<FrameworkCase frameworks={["html"]}>
```css
media-placeholder {
  position: absolute;
  inset: 0;
  background-size: cover;
  background-position: center;
  filter: blur(20px);
}

media-placeholder:not([data-visible]) {
  opacity: 0;
}
```
</FrameworkCase>

<FrameworkCase frameworks={["react"]}>
React renders a `<div>` with the same data attribute. Add a `className` and use it as the selector:

```css
.media-placeholder {
  position: absolute;
  inset: 0;
  background-size: cover;
  background-position: center;
  filter: blur(20px);
}

.media-placeholder:not([data-visible]) {
  opacity: 0;
}
```
</FrameworkCase>

The packaged skins already carry these rules. Their blur radius comes from `--media-placeholder-blur`, which defaults to `20px`.

## Accessibility

The placeholder is decorative. It has no accessible name and screen readers skip it — a blurred copy of the poster carries nothing the poster does not. Describe the image on the <DocsLink slug="reference/poster">poster</DocsLink> instead.
