## Import

<FrameworkCase frameworks={["react"]}>
```tsx
import { selectBuffer, usePlayer } from '@videojs/react';
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import { PlayerController, UIElement, playerContext, selectBuffer } from '@videojs/html';
```
</FrameworkCase>

## Usage

`selectBuffer` reads the <DocsLink slug="reference/feature-buffer">buffer feature</DocsLink> from player state. It returns `undefined` when the feature is not configured.

<FrameworkCase frameworks={["react"]}>
Pass it to <DocsLink slug="reference/use-player">`usePlayer`</DocsLink> to subscribe to buffer state.

```tsx
const buffer = usePlayer(selectBuffer);
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Pass it to <DocsLink slug="reference/player-controller">`PlayerController`</DocsLink> to subscribe from a custom element.

```ts
class BufferControl extends UIElement {
  readonly #buffer = new PlayerController(this, playerContext, selectBuffer);
}
```
</FrameworkCase>
