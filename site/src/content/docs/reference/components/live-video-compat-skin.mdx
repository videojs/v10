The Compat skin of the live video preset: the same core controls with plain, unbranded surfaces that avoid newer visual effects such as backdrop blur. It puts a large play button in the center, fullscreen, picture-in-picture, Cast, and AirPlay in a top corner, and a Live button in place of time controls. The preset also provides <DocsLink slug="reference/components/live-video-skin">LiveVideoSkin</DocsLink> and <DocsLink slug="reference/components/live-video-neutral-skin">NeutralLiveVideoSkin</DocsLink>. See <DocsLink slug="guides/skins" anchor="choose-a-skin">Skins</DocsLink> to choose between them and <DocsLink slug="guides/customize-skins">Customize skins</DocsLink> to install and edit its source.

## Usage

The skin goes between the player and the media element. It renders its controls around the media.

<FrameworkCase frameworks={["react"]}>
```tsx
<LiveVideoPlayer>
  <CompatLiveVideoSkin>
    <HlsVideo src="live.m3u8" />
  </CompatLiveVideoSkin>
</LiveVideoPlayer>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<live-video-player>
  <live-video-compat-skin>
    <hls-video src="live.m3u8"></hls-video>
  </live-video-compat-skin>
</live-video-player>
```
</FrameworkCase>

The examples use the lightweight <DocsLink slug="reference/components/hls-video">HLS video element</DocsLink> because most browsers can't play HLS streams with a plain `<video>`. See <DocsLink slug="guides/live-streams">Play live streams</DocsLink>.

## Poster

<FrameworkCase frameworks={["react"]}>
The skin renders a poster image before playback starts. Pass `renderPoster` to replace it with your own component.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
The skin renders a poster image before playback starts. An element with `slot="poster"` replaces it.
</FrameworkCase>

See <DocsLink slug="guides/poster">Add a poster and loading placeholder</DocsLink> for complete examples.

## Styling

Packaged skins style themselves and expose a small set of public CSS custom properties. Everything else inside the skin is private and may change between releases. <DocsLink slug="guides/customize-skins" anchor="style-a-packaged-skin">Customize skins</DocsLink> documents the properties. For deeper changes, the Video.js registry provides the skin files.
