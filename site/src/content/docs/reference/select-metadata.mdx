## Import

<FrameworkCase frameworks={["react"]}>
```tsx
import { selectMetadata, usePlayer } from '@videojs/react';
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import { PlayerController, UIElement, playerContext, selectMetadata } from '@videojs/html';
```
</FrameworkCase>

## Usage

`selectMetadata` reads the <DocsLink slug="reference/feature-metadata">metadata feature</DocsLink> from player state. It returns `undefined` when the feature is not configured.

<FrameworkCase frameworks={["react"]}>
Pass it to <DocsLink slug="reference/use-player">`usePlayer`</DocsLink> to subscribe to metadata state.

```tsx
const metadata = usePlayer(selectMetadata);
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Pass it to <DocsLink slug="reference/player-controller">`PlayerController`</DocsLink> to subscribe from a custom element.

```ts
class MetadataElement extends UIElement {
  readonly #metadata = new PlayerController(this, playerContext, selectMetadata);
}
```
</FrameworkCase>
