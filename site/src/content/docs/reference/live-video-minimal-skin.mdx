The minimal skin of the live video preset: the same player and the same controls in a visually lighter design, closer to a classic control bar. Like the default skin, it shows a Live button in place of time controls. <DocsLink slug="reference/live-video-skin">LiveVideoSkin</DocsLink> is the same preset's other variant. See <DocsLink slug="concepts/skins">Skins</DocsLink> for how packaged skins work and <DocsLink slug="concepts/presets">Presets</DocsLink> for what the live video preset ships.

## Import

<SkinImports preset="live-video" react="MinimalLiveVideoSkin" minimal />

## Usage

The skin goes between the player and the media element. It renders its controls around the media.

<FrameworkCase frameworks={["react"]}>
```tsx
<LiveVideoPlayer>
  <MinimalLiveVideoSkin>
    <HlsVideo src="live.m3u8" />
  </MinimalLiveVideoSkin>
</LiveVideoPlayer>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<live-video-player>
  <live-video-minimal-skin>
    <hls-video src="live.m3u8"></hls-video>
  </live-video-minimal-skin>
</live-video-player>
```
</FrameworkCase>

The examples use the default <DocsLink slug="reference/hls-video">HLS video element</DocsLink> because most browsers can't play HLS streams with a plain `<video>`. See <DocsLink slug="how-to/play-live-streams">Play live streams</DocsLink>.

## Poster

<FrameworkCase frameworks={["react"]}>
The skin renders a poster image before playback starts. Pass `renderPoster` to replace it with your own component.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
The skin renders a poster image before playback starts. An element with `slot="poster"` replaces it.
</FrameworkCase>

See <DocsLink slug="how-to/add-a-poster-and-loading-placeholder">Add a poster and loading placeholder</DocsLink> for complete examples.

## Styling

Packaged skins style themselves and expose a small set of public CSS custom properties. Everything else inside the skin is private and may change between releases. <DocsLink slug="how-to/customize-skins" anchor="customize-a-packaged-skin">Customize skins</DocsLink> documents the properties. When you need deeper changes, eject the skin.
