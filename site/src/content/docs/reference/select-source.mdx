## Import

<FrameworkCase frameworks={["react"]}>

```tsx
import { selectSource, usePlayer } from '@videojs/react';
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import { PlayerController, UIElement, playerContext, selectSource } from '@videojs/html';
```
</FrameworkCase>

## Usage

`selectSource` reads the <DocsLink slug="reference/feature-source">source feature</DocsLink> from player state. It returns `undefined` when the feature is not configured.

<FrameworkCase frameworks={["react"]}>
Pass it to <DocsLink slug="reference/use-player">`usePlayer`</DocsLink> to subscribe to source state.

```tsx
const source = usePlayer(selectSource);
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Pass it to <DocsLink slug="reference/player-controller">`PlayerController`</DocsLink> to subscribe from a custom element.

```ts
class SourceElement extends UIElement {
  readonly #source = new PlayerController(this, playerContext, selectSource);
}
```
</FrameworkCase>
