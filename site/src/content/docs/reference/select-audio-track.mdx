## Import

<FrameworkCase frameworks={["react"]}>
```tsx
import { selectAudioTrack, usePlayer } from '@videojs/react';
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import { PlayerController, UIElement, playerContext, selectAudioTrack } from '@videojs/html';
```
</FrameworkCase>

## Usage

`selectAudioTrack` reads the <DocsLink slug="reference/feature-audio-track">audio track feature</DocsLink> from player state. It returns `undefined` when the feature is not configured.

<FrameworkCase frameworks={["react"]}>
Pass it to <DocsLink slug="reference/use-player">`usePlayer`</DocsLink> to subscribe to audio track state.

```tsx
const audioTrack = usePlayer(selectAudioTrack);
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Pass it to <DocsLink slug="reference/player-controller">`PlayerController`</DocsLink> to subscribe from a custom element.

```ts
class AudioTrackControl extends UIElement {
  readonly #audioTrack = new PlayerController(this, playerContext, selectAudioTrack);
}
```
</FrameworkCase>
