## Import

<FrameworkCase frameworks={["react"]}>
```tsx
import { selectControls, usePlayer } from '@videojs/react';
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import { PlayerController, UIElement, playerContext, selectControls } from '@videojs/html';
```
</FrameworkCase>

## Usage

`selectControls` reads the <DocsLink slug="reference/feature-controls">controls feature</DocsLink> from player state. It returns `undefined` when the feature is not configured.

<FrameworkCase frameworks={["react"]}>
Pass it to <DocsLink slug="reference/use-player">`usePlayer`</DocsLink> to subscribe to controls state.

```tsx
const controls = usePlayer(selectControls);
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Pass it to <DocsLink slug="reference/player-controller">`PlayerController`</DocsLink> to subscribe from a custom element.

```ts
class ControlsElement extends UIElement {
  readonly #controls = new PlayerController(this, playerContext, selectControls);
}
```
</FrameworkCase>
