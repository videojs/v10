## Import

<FrameworkCase frameworks={["react"]}>

```tsx
import { selectTime, usePlayer } from '@videojs/react';
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import { PlayerController, UIElement, playerContext, selectTime } from '@videojs/html';
```
</FrameworkCase>

## Usage

`selectTime` reads the <DocsLink slug="reference/feature-time">time feature</DocsLink> from player state. It returns `undefined` when the feature is not configured.

<FrameworkCase frameworks={["react"]}>
Pass it to <DocsLink slug="reference/use-player">`usePlayer`</DocsLink> to subscribe to time state.

```tsx
const time = usePlayer(selectTime);
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Pass it to <DocsLink slug="reference/player-controller">`PlayerController`</DocsLink> to subscribe from a custom element.

```ts
class TimeElement extends UIElement {
  readonly #time = new PlayerController(this, playerContext, selectTime);
}
```
</FrameworkCase>
