## Import

<FrameworkCase frameworks={["react"]}>
```tsx
import { selectPiP, usePlayer } from '@videojs/react';
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import { PlayerController, UIElement, playerContext, selectPiP } from '@videojs/html';
```
</FrameworkCase>

## Usage

`selectPiP` reads the <DocsLink slug="reference/feature-pip">picture-in-picture feature</DocsLink> from player state. It returns `undefined` when the feature is not configured.

<FrameworkCase frameworks={["react"]}>
Pass it to <DocsLink slug="reference/use-player">`usePlayer`</DocsLink> to subscribe to picture-in-picture state.

```tsx
const pictureInPicture = usePlayer(selectPiP);
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Pass it to <DocsLink slug="reference/player-controller">`PlayerController`</DocsLink> to subscribe from a custom element.

```ts
class PictureInPictureControl extends UIElement {
  readonly #pictureInPicture = new PlayerController(this, playerContext, selectPiP);
}
```
</FrameworkCase>
