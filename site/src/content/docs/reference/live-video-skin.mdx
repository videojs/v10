The default skin of the live video preset: the video layout with the time slider and time displays swapped for a Live button. <DocsLink slug="reference/live-video-minimal-skin">MinimalLiveVideoSkin</DocsLink> is the same preset's other variant. See <DocsLink slug="concepts/skins">Skins</DocsLink> for how packaged skins work and <DocsLink slug="concepts/presets">Presets</DocsLink> for what the live video preset ships.

## Import

<SkinImports preset="live-video" react="LiveVideoSkin" />

## Usage

The skin nests between the player and the media element and renders its controls around the media it wraps.

<FrameworkCase frameworks={["react"]}>
```tsx
<LiveVideoPlayer>
  <LiveVideoSkin>
    <Video src="live.m3u8" />
  </LiveVideoSkin>
</LiveVideoPlayer>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<live-video-player>
  <live-video-skin>
    <video src="live.m3u8"></video>
  </live-video-skin>
</live-video-player>
```
</FrameworkCase>

## Poster

<FrameworkCase frameworks={["react"]}>
The skin renders a poster image before playback starts. Pass `renderPoster` to replace it with your own component.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
The skin renders a poster image before playback starts. An element with `slot="poster"` replaces it.
</FrameworkCase>

See <DocsLink slug="how-to/add-a-poster-and-loading-placeholder">Add a poster and loading placeholder</DocsLink> for complete examples.

## Styling

Packaged skins style themselves and expose a small set of public CSS custom properties. Everything else inside the skin is private and may change between releases. <DocsLink slug="how-to/customize-skins">Customize skins</DocsLink> documents the properties and the ejection path when you need deeper changes.
