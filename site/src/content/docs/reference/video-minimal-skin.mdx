The minimal skin of the video preset: the same player and the same controls in a visually lighter design, closer to a classic control bar. <DocsLink slug="reference/video-skin">VideoSkin</DocsLink> is the same preset's other variant. See <DocsLink slug="concepts/skins">Skins</DocsLink> for how packaged skins work and <DocsLink slug="concepts/presets">Presets</DocsLink> for what the video preset ships.

## Import

<SkinImports preset="video" react="MinimalVideoSkin" minimal />

## Usage

The skin goes between the player and the media element. It renders its controls around the media.

<FrameworkCase frameworks={["react"]}>
```tsx
<VideoPlayer>
  <MinimalVideoSkin>
    <Video src="video.mp4" />
  </MinimalVideoSkin>
</VideoPlayer>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<video-player>
  <video-minimal-skin>
    <video src="video.mp4"></video>
  </video-minimal-skin>
</video-player>
```
</FrameworkCase>

## Poster

<FrameworkCase frameworks={["react"]}>
The skin renders a poster image before playback starts. Pass `renderPoster` to replace it with your own component.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
The skin renders a poster image before playback starts. An element with `slot="poster"` replaces it.
</FrameworkCase>

See <DocsLink slug="how-to/add-a-poster-and-loading-placeholder">Add a poster and loading placeholder</DocsLink> for complete examples.

## Styling

Packaged skins style themselves and expose a small set of public CSS custom properties. Everything else inside the skin is private and may change between releases. <DocsLink slug="how-to/style-a-packaged-skin">Style a packaged skin</DocsLink> documents the properties. When you need deeper changes, install the skin's source.
