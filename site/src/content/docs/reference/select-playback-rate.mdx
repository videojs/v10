
<FrameworkCase frameworks={["html"]}>
```ts
import { PlayerController, UIElement, playerContext, selectPlaybackRate } from '@videojs/html';
```

## Usage

`selectPlaybackRate` reads the <DocsLink slug="reference/feature-playback-rate">playback rate feature</DocsLink> from player state. It returns `undefined` when the feature is not configured.

<FrameworkCase frameworks={["react"]}>
Pass it to <DocsLink slug="reference/use-player">`usePlayer`</DocsLink> to subscribe to playback rate state.

```tsx
const playbackRate = usePlayer(selectPlaybackRate);
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Pass it to <DocsLink slug="reference/player-controller">`PlayerController`</DocsLink> to subscribe from a custom element.

```ts
class PlaybackRateControl extends UIElement {
  readonly #playbackRate = new PlayerController(this, playerContext, selectPlaybackRate);
}
```
</FrameworkCase>
