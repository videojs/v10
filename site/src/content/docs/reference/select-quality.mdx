## Import

<FrameworkCase frameworks={["react"]}>
```tsx
import { selectQuality, usePlayer } from '@videojs/react';
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import { PlayerController, UIElement, playerContext, selectQuality } from '@videojs/html';
```
</FrameworkCase>

## Usage

`selectQuality` reads the <DocsLink slug="reference/feature-quality">quality feature</DocsLink> from player state. It returns `undefined` when the feature is not configured.

<FrameworkCase frameworks={["react"]}>
Pass it to <DocsLink slug="reference/use-player">`usePlayer`</DocsLink> to subscribe to quality state.

```tsx
const quality = usePlayer(selectQuality);
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Pass it to <DocsLink slug="reference/player-controller">`PlayerController`</DocsLink> to subscribe from a custom element.

```ts
class QualityControl extends UIElement {
  readonly #quality = new PlayerController(this, playerContext, selectQuality);
}
```
</FrameworkCase>
