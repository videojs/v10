## Import

<FrameworkCase frameworks={["react"]}>
```tsx
import { selectPlayback, usePlayer } from '@videojs/react';
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```ts
import { PlayerController, UIElement, playerContext, selectPlayback } from '@videojs/html';
```
</FrameworkCase>

## Usage

`selectPlayback` reads the <DocsLink slug="reference/feature-playback">playback feature</DocsLink> from player state. It returns `undefined` when the feature is not configured.

<FrameworkCase frameworks={["react"]}>
Pass it to <DocsLink slug="reference/use-player">`usePlayer`</DocsLink> to subscribe to playback state.

```tsx
const playback = usePlayer(selectPlayback);
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
Pass it to <DocsLink slug="reference/player-controller">`PlayerController`</DocsLink> to subscribe from a custom element.

```ts
class PlaybackControl extends UIElement {
  readonly #playback = new PlayerController(this, playerContext, selectPlayback);
}
```
</FrameworkCase>
