The default skin of the live audio preset: the audio layout with the time slider and time displays swapped for a Live button. <DocsLink slug="reference/live-audio-minimal-skin">MinimalLiveAudioSkin</DocsLink> is the same preset's other variant. See <DocsLink slug="concepts/skins">Skins</DocsLink> for how packaged skins work and <DocsLink slug="concepts/presets">Presets</DocsLink> for what the live audio preset ships.

## Import

<SkinImports preset="live-audio" react="LiveAudioSkin" />

## Usage

The skin goes between the player and the media element. It renders its controls around the media.

<FrameworkCase frameworks={["react"]}>
```tsx
<LiveAudioPlayer>
  <LiveAudioSkin>
    <MuxAudio src="live.m3u8" />
  </LiveAudioSkin>
</LiveAudioPlayer>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<live-audio-player>
  <live-audio-skin>
    <mux-audio src="live.m3u8"></mux-audio>
  </live-audio-skin>
</live-audio-player>
```
</FrameworkCase>

The examples use the <DocsLink slug="reference/mux-audio">Mux audio element</DocsLink>: a plain `<audio>` can't play HLS in most browsers, and this element reports the live playback state the skin's Live button needs. See <DocsLink slug="how-to/play-live-streams">Play live streams</DocsLink>.

## Styling

Packaged skins style themselves and expose a small set of public CSS custom properties. Everything else inside the skin is private and may change between releases. <DocsLink slug="how-to/customize-skins" anchor="style-a-packaged-skin">Customize skins</DocsLink> documents the properties. When you need deeper changes, install the skin's source.
