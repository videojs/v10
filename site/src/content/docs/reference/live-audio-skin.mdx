The default skin of the live audio preset: the audio layout with the time slider and time displays swapped for a Live button. <DocsLink slug="reference/live-audio-minimal-skin">MinimalLiveAudioSkin</DocsLink> is the same preset's other variant. See <DocsLink slug="concepts/skins">Skins</DocsLink> for how packaged skins work and <DocsLink slug="concepts/presets">Presets</DocsLink> for what the live audio preset ships.

## Import

<SkinImports preset="live-audio" react="LiveAudioSkin" />

## Usage

The skin goes between the player and the media element. It renders its controls around the media.

<FrameworkCase frameworks={["react"]}>
```tsx
<LiveAudioPlayer>
  <LiveAudioSkin>
    <HlsAudio src="live.m3u8" />
  </LiveAudioSkin>
</LiveAudioPlayer>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<live-audio-player>
  <live-audio-skin>
    <hls-audio src="live.m3u8"></hls-audio>
  </live-audio-skin>
</live-audio-player>
```
</FrameworkCase>

The examples use the default <DocsLink slug="reference/hls-audio">HLS audio element</DocsLink> because most browsers can't play HLS streams with a plain `<audio>`. See <DocsLink slug="how-to/play-live-streams">Play live streams</DocsLink>.

## Styling

Packaged skins style themselves and expose a small set of public CSS custom properties. Everything else inside the skin is private and may change between releases. <DocsLink slug="how-to/customize-skins">Customize skins</DocsLink> documents the properties and the ejection path when you need deeper changes.
