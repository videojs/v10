Use Shadcn to add a Video.js skin's components, layout, styles, and interactions to your React or HTML project. The CLI copies the files into your app so you can change them like any other source code.

<ReleaseCandidateNotice />

## Choose your installation method

Start with packages, add editable source, or load the browser-ready player from a CDN.

<InstallationMethodNav />

<Aside type="note">
Commit your work before installing or updating source so you can review every file the CLI adds or replaces.
</Aside>

## Initialize Shadcn

Run the commands from the app directory that contains `components.json`, or where you want the CLI to create it. In a monorepo, run them from the app workspace or pass `--cwd <path>`.

<ShadcnFrameworkCase framework="react">
<RegistryOptions framework="react" kind="template" />

<RegistryInitCommand framework="react" installation />
</ShadcnFrameworkCase>

<ShadcnFrameworkCase framework="html">
<RegistryOptions framework="html" kind="template" />

<RegistryInitCommand framework="html" installation />
</ShadcnFrameworkCase>

If the app already has `components.json`, skip this section.

## Add the skin source

React skins can use Tailwind CSS 4 or Vanilla CSS. HTML skins use Vanilla CSS. Choose the styling that matches your app, then connect the Video.js registry and add the skin selected above.

<ShadcnFrameworkCase framework="react">
<RegistryOptions framework="react" kind="styling" />

<InstallationRegistryCommand framework="react" />

The files are added under `components/videojs/<preset>`. The registry item also installs `@videojs/react`.
</ShadcnFrameworkCase>

<ShadcnFrameworkCase framework="html">
<RegistryOptions framework="html" kind="styling" />

<InstallationRegistryCommand framework="html" />

The files are added under `components/videojs/<preset>`. The registry item also installs `@videojs/html`.
</ShadcnFrameworkCase>

<SourceMediaInstall client:idle />

## Add your player

<ShadcnFrameworkCase framework="react">
Add the player directly to `app/page.tsx`. It imports the player and media from the package, then imports the selected skin from your project.

<ContentWidth>
  <SourceReactPlayer client:idle />
</ContentWidth>
</ShadcnFrameworkCase>

<ShadcnFrameworkCase framework="html">
<Steps>
  <Step number={1} title="Add the media element">
    <SourceHTMLPlayer client:idle part="media" />
  </Step>
  <Step number={2} title="Register the custom elements">
    <SourceHTMLPlayer client:idle part="imports" />
  </Step>
  <Step number={3} title="Add the player to your page">
    <SourceHTMLPlayer client:idle part="player" />
  </Step>
</Steps>
</ShadcnFrameworkCase>

That's it! You now have a working Video.js player whose skin source lives in your project.

## Change the skin source

Start in `components/videojs/<preset>/skin.tsx` for React or `components/videojs/<preset>/skin.html` for HTML. Follow the [Customize skins](/docs/framework/react/guides/customize-skins#style-skin-source) guide for the files that control layout, colors, controls, and interactions.
