## Choose source styling

React skin source is available with Tailwind CSS 4 or Vanilla CSS. HTML source for HTML, Vue, and Svelte uses Vanilla CSS.

<RegistryOptions framework="react" kind="styling" />

## Prepare your app

Skip this section when you already have the selected app setup. For a new React and Tailwind app, run the command from the parent directory: Shadcn creates the named app and `components.json` together. The other paths scaffold into the current empty app directory before you add the standard config below.

<ProjectCommands client:load method="shadcn" part="create" serverFramework="react" serverTemplate="next" />

## Configure the source registry

For an existing React and Tailwind app without `components.json`, satisfy Shadcn's Tailwind and import-alias checks, then run the command below. The other paths show the aliases and standard config to merge into the app. In a monorepo, use the app workspace or pass `--cwd <path>` to Shadcn commands.

<Aside type="note">
Commit your work before installing or updating source so you can review every file the CLI adds or replaces.
</Aside>

<ShadcnFrameworkCase framework="react">
<RegistryInitCommand framework="react" installation />
</ShadcnFrameworkCase>

<ShadcnFrameworkCase framework="html">
<RegistryInitCommand framework="html" installation />
</ShadcnFrameworkCase>

If the app already has `components.json`, keep its aliases and skip this section. The registry writes source under its `aliases.components` path, so use that existing alias in the imports below. Vanilla CSS, HTML, Vue, and Svelte use the compatible `components.json` shown above without adding React or Tailwind setup.

## Add the skin source

Set the Video.js registry catalog in `components.json`, then add the skin selected above.

The add command overwrites an existing Video.js skin so theme or catalog changes apply completely. Review and remove obsolete Video.js style files left by an earlier catalog. For HTML source, repeat the media replacement below after an overwrite.

<ShadcnFrameworkCase framework="react">
<InstallationRegistryCommand framework="react" />

The files are added under `<components alias>/videojs/<preset>`. The registry item also installs `@videojs/react`.
</ShadcnFrameworkCase>

<ShadcnFrameworkCase framework="html">
<InstallationRegistryCommand framework="html" />

</ShadcnFrameworkCase>

## Change the skin source

<ShadcnFrameworkCase framework="react">
Start in `<components alias>/videojs/<preset>/skin.tsx`. Follow the [Customize skins](/docs/framework/react/guides/customize-skins#style-skin-source) guide for the files that control layout, colors, controls, and interactions.
</ShadcnFrameworkCase>

<ShadcnFrameworkCase framework="html">
Start in `<components alias>/videojs/<preset>/skin.html`. Follow the [Customize skins](/docs/framework/html/guides/customize-skins#style-skin-source) guide for the files that control layout, colors, controls, and interactions.
</ShadcnFrameworkCase>
