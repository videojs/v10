Use Shadcn when you want the skin's components, layout, styles, and interactions in your project. The CLI copies the files; you can then change them like any other source code.

<Aside type="note">
Commit your work before installing or updating source so you can review every file the CLI adds or replaces.
</Aside>

## Add the skin source and build your player

Run the commands from the app directory that contains `components.json`, or where you want the CLI to create it. In a monorepo, run them from the app workspace or pass `--cwd <path>`.

## Change the skin source

Start in `components/videojs/<skin>/skin.tsx` for React or `skin.html` for HTML. Follow the [Customize skins](/docs/framework/react/guides/customize-skins#style-skin-source) guide for the files that control layout, colors, controls, and interactions.
