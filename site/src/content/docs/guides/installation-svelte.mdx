Video.js does not ship a first-party Svelte package yet, so Svelte and SvelteKit apps use the `@videojs/html` custom elements directly in their markup.

## Install Video.js

Install the HTML elements and the hls.js adapter. `@videojs/html` plays MP4 files on its own; the adapter adds cross-browser HLS playback for the `.m3u8` source used below.

## Create your player

Add a component that imports the elements it renders. Svelte passes hyphenated tags through to the browser, so no compiler configuration is needed. The imports register `<video-player>`, `<video-skin>`, and `<hlsjs-video>`; the markup composes them.

```svelte title="src/lib/VideoPlayer.svelte"
<script lang="ts">
  import '@videojs/html/video/player';
  import '@videojs/html/video/skin';
  import '@videojs/html/media/hlsjs-video';

  let { src }: { src: string } = $props();
</script>

<!--
  The player element owns and shares state between the UI
  components and Media. Put layout on the skin or container.
-->
<video-player>
  <!--
    Skins contain the entire player UI and are easily swappable.
    They can each be "ejected" for full control and customization
    of UI components.
  -->
  <video-skin>
    <!--
      Media are players without UIs, handling networking
      and display of the media. They are easily swappable
      to handle different sources.
    -->
    <hlsjs-video {src} playsinline></hlsjs-video>
  </video-skin>
</video-player>
```

## Use your player

Render the component in a page and pass it a source.

  <TabsList client:idle label="App type">

  </TabsList>
  <TabsPanel client:idle value="sveltekit" initial>

    <h1>Welcome to My App</h1>

</TabsRoot>

That's it! You now have a working Video.js player.

<Aside type="note" title="Server rendering with SvelteKit">
Keep the element imports static. SvelteKit renders the custom-element markup on the server, and the browser upgrades it when the page loads. Put code that needs the element or browser APIs in `onMount`. See <DocsLink slug="guides/use-videojs-with-svelte" anchor="use-sveltekit">Use SvelteKit</DocsLink> for the details.
</Aside>
