A packaged skin is one import. When you need to rearrange controls, change markup, or own every style, install the skin's source instead. We call the result Source-Owned UI: the Shadcn CLI copies the skin from the Video.js registry into your project, where it becomes files you edit like any other component.

<Aside type="note">
Start with a packaged skin. Install the source once the public CSS custom properties in <DocsLink slug="how-to/customize-skins">Customize skins</DocsLink> stop being enough.
</Aside>

## Choose your styling

<FrameworkCase frameworks={["react"]}>
The React catalogs publish every skin in Tailwind CSS 4 and in vanilla CSS. Pick the one your project uses. The choice selects the catalog the `@videojs` namespace points at; item names stay the same.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
The HTML catalog publishes every skin in vanilla CSS. Skins arrive as light-DOM markup, a registration module, and a stylesheet.
</FrameworkCase>

## Set up the registry

Initialize Shadcn if your project has no `components.json` yet:

<ShadcnCommand action="init" />

Then register the Video.js registry as the `@videojs` namespace. The command writes the catalog URL into `components.json`, so every later command can refer to items as `@videojs/<item>`:

<RegistryCommand />

## Install a skin

Default skins are named after their preset, and Minimal skins add `-minimal`:

<ShadcnCommand action="add @videojs/video" />

The CLI installs the skin's files under `components/videojs/skins/<preset>`, Minimal variants under `components/videojs/skins/<preset>/minimal`, the UI components the skin composes, and the theme stylesheet they all read their tokens from at `components/videojs/styles/theme.css`. It also adds the framework package to your dependencies.

<FrameworkCase frameworks={["react"]}>
The player and media stay imports from `@videojs/react`. Import the skin component from the installed `skin.tsx` and place your media inside it, exactly where the packaged skin sat.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
The player and media stay imports from `@videojs/html`. Import the installed `skin.ts` once to register the skin's elements and load its styles, then paste the markup from `skin.html` inside your player, around the media element. The markup is plain light DOM, so every control is in your page.
</FrameworkCase>

<FrameworkCase frameworks={["react"]}>

## Install one UI component

The React catalogs also publish each styled UI component on its own. Add a component the same way, and it brings the components and styles it depends on:

<ShadcnCommand action="add @videojs/play-button" />

</FrameworkCase>

## Inspect and update

The standard Shadcn commands work with the namespace:

```bash
npx shadcn@latest search @videojs --query volume
npx shadcn@latest view @videojs/video
npx shadcn@latest add @videojs/video --overwrite
```

Installed files are yours, so an update is a reinstall. Commit your changes first, run `add` with `--overwrite`, and review the diff in version control before you keep it.
