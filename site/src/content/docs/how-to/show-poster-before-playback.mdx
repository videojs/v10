## How it works

Poster is a player component, not the native `poster` attribute, so you can style it, transition it, and compose it with other UI. It reads playback state to know when to hide.

## Availability and constraints

Pair `preload="none"` with a poster so the player isn't a black box before playback. See <DocsLink slug="how-to/load-different-file-formats">Load different file formats</DocsLink>.

## Common variations

### Poster from the media service

Video platforms generate poster images for you — for Mux, a thumbnail URL per asset — so you rarely need to create these by hand.

## Troubleshooting

### The poster never hides

Poster reads playback state; confirm playback actually started (see <DocsLink slug="how-to/autoplay">Autoplay</DocsLink> for why it might not have).
