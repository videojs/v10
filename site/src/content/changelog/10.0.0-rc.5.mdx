This release updates the skin and store APIs ahead of 10.0, while making it easier to support older browsers, choose media from a source URL, and migrate an existing player.

## Breaking changes

- **Minimal is now Neutral** ([#3092](https://github.com/videojs/v10/pull/3092)). Replace every public `minimal` name with `neutral`: imports and exports, `Minimal*Skin` types and elements, `data-theme`, icon families, CDN bundles, Shadcn registry paths, and `--skin minimal`. The old names have no aliases. See [Customize skins](/docs/guides/customize-skins/) for the available options.
- **The player store now follows media API names** ([#3012](https://github.com/videojs/v10/pull/3012)). Replace `togglePaused()` with `play()` or `pause()`, `toggleMuted()` with `setMuted(muted)`, and the fullscreen and picture-in-picture toggles with their request and exit pairs. Rename `fullscreen` to `isFullscreen`, `pip` to `isPictureInPicture`, and `pipAvailability` to `pictureInPictureAvailability`; set a source on the media element instead of calling `loadSource(src)`.
- **Text-track state has a smaller shape** ([#3057](https://github.com/videojs/v10/pull/3057)). Replace `thumbnailCues`, `thumbnailTrackSrc`, and `thumbnailTrackCrossOrigin` with `thumbnailsTrack`, and use `selectSubtitlesTrack(null)` instead of `'off'` to turn subtitles off.
- **Manually wired extensions must move into the player** ([#2880](https://github.com/videojs/v10/pull/2880)). Mounted `<google-cast>`, `<mux-data>`, `<GoogleCast>`, and `<MuxData>` usage is unchanged. Replace `useMediaExtension`, `addMediaExtension`, and extension `setAdapter()` calls with the matching element or component inside the player.
- **Custom skin source uses `media-high-contrast`** ([#3094](https://github.com/videojs/v10/pull/3094)). Rename the Tailwind `media-opaque` variant; its reduced-transparency and contrast behavior is unchanged.

## Skins and browser support

The alternate packaged skin is now called Neutral, and a new Compat skin offers a simpler control layout with conservative CSS for video, live video, audio, and live audio. Compat is available from the HTML and React packages, CDN bundles, Shadcn registries, and installation tools ([#3026](https://github.com/videojs/v10/pull/3026)).

Packaged skins now support Chrome and Edge 111, Firefox 121, and Safari and iOS 16.4. Their bundles flatten `@scope` rules and include CSS fallbacks, while editable registry CSS keeps `@scope` for readability ([#2966](https://github.com/videojs/v10/pull/2966), [#2951](https://github.com/videojs/v10/pull/2951)). See [browser support](/docs/guides/browser-support/) for the supported-browser details.

## Media and playback

`resolveAdapterType()` and `resolveMimeType()` let HTML and React apps choose the right media component from a URL or MIME type, using the same source rules as the installation flow. They support service URLs, streams, and files, return `null` for ambiguous bare IDs, and recognize `youtube/<id>` and `vimeo/<id>` shorthands ([#3024](https://github.com/videojs/v10/pull/3024)). The new [Vidstack migration guide](/docs/guides/migrate-from-vidstack/) uses those helpers to map providers to Video.js media components ([#3021](https://github.com/videojs/v10/pull/3021)).

Google Cast and Mux Data now attach at the player, so they work with plain video and audio elements and follow media changes. The player also avoids unhandled rejections when a play or AirPlay request is declined ([#2880](https://github.com/videojs/v10/pull/2880)). Native HLS now honors a stream's `SERVER-CONTROL` hold-back when it derives the live edge, and hls.js keeps captions when media attachment follows manifest parsing ([#3027](https://github.com/videojs/v10/pull/3027), [#3099](https://github.com/videojs/v10/pull/3099)).

## Custom UI and docs

Custom UI can derive and display its own status actions with `deriveCustomStatus`, and React media components now accept `mediaRef`. On native media it receives the element; on iframe-based embeds it receives the playback adapter, while `ref` still points to the rendered element ([#3064](https://github.com/videojs/v10/pull/3064), [#3098](https://github.com/videojs/v10/pull/3098)). Core, HTML, and React also export their own `VERSION` constant for diagnostics ([#3078](https://github.com/videojs/v10/pull/3078)).

The documentation now includes a generated [player store reference](/docs/framework/react/reference/api/player-store) and updated migration and playback guides with current APIs, complete examples, and agent-ready migration prompts ([#3034](https://github.com/videojs/v10/pull/3034), [#3074](https://github.com/videojs/v10/pull/3074), [#3075](https://github.com/videojs/v10/pull/3075), [#3076](https://github.com/videojs/v10/pull/3076)). Nested menus also keep their closing transition, and the default skin reduces its backdrop saturation for clearer controls ([#3025](https://github.com/videojs/v10/pull/3025), [#3091](https://github.com/videojs/v10/pull/3091)).
