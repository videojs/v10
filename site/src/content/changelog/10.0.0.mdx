Video.js 10 is now stable. Packages publish to npm's `latest` channel, while prereleases continue on `next` ([#3058](https://github.com/videojs/v10/pull/3058)).

The [installation guide](/docs/guides/installation) no longer carries a release-candidate notice, and the README and [Video.js 8 migration guide](/docs/guides/migrate-from-video-js-8) now reflect the stable release. The [v10 roadmap](/docs/guides/v10-roadmap) now describes what comes after 10.0 ([#3058](https://github.com/videojs/v10/pull/3058)).
