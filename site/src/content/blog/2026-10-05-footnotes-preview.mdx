This post exists so we can review footnotes in a deploy preview. It gets deleted before the pull request merges.

## What to check

Click a footnote number[^click]. In browsers with CSS anchor positioning (Chrome, Edge, Safari 26, recent Firefox) its definition opens in a popover beside it. Press <kbd>Esc</kbd> or click elsewhere to close it, or click the number again. In Chrome, hovering or focusing the number opens it too[^hover]. Everywhere else, the number jumps to the definition at the end of the post, and the ↩ link jumps back.

Cmd-click or Ctrl-click a number[^modifier] to open the definition in a new tab instead.

## Edge cases

Footnotes can hold links and code[^rich]. They can run several sentences[^long]. One definition can be cited from more than one place[^reused], and each reference gets its own popover and its own way back from the definitions list.

A reference at the very end of a long line should still open a popover that stays on screen, even on a phone where the column is narrow and the reference sits right against the edge of the viewport[^edge].

> Don't communicate by sharing memory, share memory by communicating.<br/>
> — <cite>Rob Pike[^pike]</cite>

[^click]: This is the shortest kind of footnote.
[^hover]: Hover and focus use interest invokers (the `interestfor` attribute). Browsers that don't support them ignore the attribute, so clicking still works.
[^modifier]: Modified clicks keep the browser's normal link behavior.
[^rich]: Like a link to the [Video.js docs](/docs/) and some `inline code`.
[^long]: This one is longer, to show how the popover wraps. Popovers are capped at 28rem wide and wrap their text, so a long footnote turns into a short paragraph instead of a single line that runs off the screen. If a footnote gets this long, consider whether it belongs in the body text instead.
[^reused]: Both references to this footnote open the same text. The definitions list shows two back links, one for each reference.
[^edge]: The popover shifts sideways to stay inside the viewport, and flips below the reference when there isn't room above it.
[^pike]: The above quote is excerpted from Rob Pike's [talk](https://www.youtube.com/watch?v=PAAkCSZUG1c) during Gopherfest, November 18, 2015.
[^list]: A footnote inside a list item.
[^hlsjs]: Defaults to 30 seconds.
